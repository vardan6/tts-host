First public alpha of TTS Host for Windows: select text anywhere and hear it,
spoken locally on your PC. Nothing is sent to the internet.

This is a tester build. Features, settings, and file formats may still change.

## Install

Download `tts-host-0.1.0-alpha.1-setup.exe` and run it. It needs no
administrator rights and no network: the Kokoro English voice model is
included. `tts-host-0.1.0-alpha.1-portable.zip` is the same without
installing: unzip it anywhere and run `tts-host.exe`.

This release is the standard version only (Kokoro, CPU, any 64-bit Windows
PC). The NVIDIA version with Qwen3-TTS is not part of this alpha; Settings
lists Qwen as needing it.

## "Windows protected your PC"

Alpha builds are not code-signed, so Windows SmartScreen warns before the
installer runs. Click **More info**, then **Run anyway**.

## Use it

TTS Host runs in the tray. Select text in any application and press
**Ctrl+F8**. If an application does not expose its selection, TTS Host says so
and asks you to copy the text. Right-click the tray icon for Settings and Now
Playing.

## Browser extension

To control playback from Chrome or Edge, open the extensions page, turn on
**Developer mode**, choose **Load unpacked**, and pick the `extension` folder
in the install folder (`%LOCALAPPDATA%\Programs\TTS Host\extension`) or in the
unzipped portable folder.

## Report problems

Open an issue at https://github.com/vardan6/tts-host/issues with what you did,
what happened, and your Windows version.
